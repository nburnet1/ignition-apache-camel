# Jython Definitions

These pages use a runnable Ignition project called `MyProject` and a project
script named `camel_demo`. The script defines a route, a processor, and a bean
factory.

- [Routes](routes/) — connect endpoints and processing steps.
- [Beans](beans/) — create named objects through a factory.
- [Processor](processor/) — read or change an exchange.
